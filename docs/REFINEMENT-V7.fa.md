# V7 — اصلاح حرکت، داستان و جزئیات تصویری

## تغییرهای اصلی

### همراه زنبور

حرکت قدیمی حذف و با یک دنبال‌کنندهٔ اسکرول مستقل جایگزین شده است:

- موقعیت و سرعت در طول صفحه و هنگام دریافت محصولات حفظ می‌شوند؛ هیچ آغاز دوباره از مرکز یا مختصات صفر وجود ندارد.
- زنبور در ناحیهٔ بدون تیتر ناپدید نمی‌شود؛ در حاشیهٔ خواندن همراه اسکرول می‌ماند.
- مسیر پرواز تابع موقعیت و جهت اسکرول است، نه پرش بین تیترها یا چرخش تصادفیِ وابسته به زمان.
- پس از مکث، با منحنی کوتاه و سرعت/شتاب محدود به تیتر نزدیک می‌شود و می‌نشیند؛ با ادامهٔ اسکرول آرام بلند می‌شود.
- لایهٔ همراه مستقیماً زیر body قرار می‌گیرد، نه داخل wrapperهای transformدار ورود صفحه یا reveal. تغییرات فونت و ارتفاع محتوا مقصد را به‌روز می‌کنند، بدون reset موقعیت.
- در موبایل هم همراه کوچک فعال است. با reduced-motion غیرفعال و با دکمهٔ Hero خاموش/روشن می‌شود. در صفحات دیگر Home همراه متحرک نصب نمی‌شود.
- طرح SVG جدید با بال‌های رگ‌دار، شش پا، شاخک و جزئیات بدن، همچنان دوبعدی و تزئینی است؛ لوگوی رسمی تغییر نکرده است.

## صفحهٔ داستان ارکام

ریشهٔ خرابی، تداخل نام کلاس `story-chapters` بین محتوای داستان و منوی fixed صفحهٔ Home بود. منو اکنون `story-wayfinder` است و داستان در کامپوننت مستقل `BrandStory` و جریان عادی سند قرار دارد. متن موجود سرور بدون حذف پاراگراف‌ها در مقدمه و یادداشت‌های شماره‌دار نمایش داده می‌شود. چیدمان دسکتاپ و موبایل، قاب عکس، بخش پایانی و لینک‌های مجموعه/مجله اصلاح شده‌اند.

اگر مالک تصویر واقعی سفارشی برای داستان ثبت کرده باشد، همان استفاده می‌شود. فقط تصویر پیش‌فرض/دمو با تصویر مفهومی جدید همراه فایل جایگزین می‌شود؛ دادهٔ پایگاه داده بازنویسی نمی‌شود.

## پترن و تصاویر

- پترن SVG حکاکی‌مانند از شاخهٔ آویشن، گل، نقطه و شش‌ضلعی به صفحات اضافه شده است؛ روی فرم‌های ورود، سبد و مدیریت بسیار کم‌رنگ‌تر است.
- قاب دوبل تیترها، خطوط ظریف فصل‌ها، حاشیه‌های گالری و جزئیات صفحهٔ داستان اضافه شده‌اند.
- سه تصویر تحریریهٔ جدید: کندو و عسل روی سنگ روشن، زنبور و شکوفه، چشم‌انداز کندوها در کوهپایه. این‌ها تصاویر مفهومی تولیدشده با AI هستند، نه عکاسی محصولات یا مزرعهٔ واقعی ارکام.
- خروجی اصلی ۱۲۶۴×۸۴۸ و نسخهٔ کوچک ۷۶۰×۵۱۰ است؛ WebP با کیفیت بالا، srcset و اندازهٔ مشخص برای پایداری چیدمان. تصویرها به‌صورت مصنوعی به 4K بزرگ نشده‌اند و نباید به‌عنوان عکس 4K معرفی شوند.
- عکس‌های محصولات موجود، نشان اصلی، قیمت‌ها و داده‌های واقعی مالک دست‌نخورده‌اند. فایل‌های محصول دمو همچنان همان داده‌های نمونهٔ قبلی‌اند.

## آزمون و محدوده

Build TypeScript/Vite، تست‌های حرکت و طراحی و مجموعهٔ کامل Django/خرید مرورگری اجرا شده‌اند. گزارش‌های این نسخه `qa/reports/v7-*` هستند. آزمون حرکت، نمونه‌های فریم‌به‌فریم را در اسکرول پایین/بالا ثبت می‌کند و نبود پنهان‌شدن و جابه‌جایی ناگهانی را بررسی می‌کند. آزمون داستان، باقی‌ماندن تمام پاراگراف‌ها، عرض کامل سند، رفتن از لینک Home و موبایل را کنترل می‌کند. آزمون‌ها Chromium headless و شبیه‌سازی viewport هستند؛ نه تست همهٔ مرورگرها یا FPS دستگاه فیزیکی.

## نصب روی Docker موجود

این نسخه migration یا تغییر بک‌اند ندارد؛ بااین‌حال مرحلهٔ معمول migrate برای سازگاری نگه داشته می‌شود. پیش از جایگزینی کد از نصب فعلی نسخهٔ پشتیبان بگیرید:

```bash
sh scripts/backup.sh
```

فایل‌های نسخهٔ جدید را در همان پوشهٔ پروژه جایگزین کنید، اما `.env` و نسخه‌های پشتیبان را حفظ کنید. سپس:

```bash
docker compose build backend frontend
docker compose run --rm migrate
docker compose up -d backend frontend
docker compose ps -a
```

هر دو image باید از یک کد ساخته شوند. دیتابیس یا volume را حذف نکنید؛ `down -v` برای ارتقا ممنوع است. به `seed_demo` برای این اصلاحات نیاز نیست. رمز مدیر و داده‌های قبلی حفظ می‌شوند. اگر صفحهٔ قدیمی کش شده، پس از آماده‌شدن سرویس‌ها reload کامل مرورگر انجام دهید. در صورت خطا، لاگ همان سرویس را بررسی کنید؛ فایل .env را عمومی ارسال نکنید.

Docker در محیط این کار اجرا نشده و این بسته به سرور مالک push/deploy نشده است. محدودیت‌های فروش واقعی، داده‌های دمو و درگاه نسخه‌های قبل همچنان پابرجاست.

## پیش‌نمایش مستقل

`ARKHAM-refined-v7-preview.html` خانه و صفحهٔ داستان را با همان کامپوننت‌ها نشان می‌دهد. لینک داستان در این فایل هم کار می‌کند. فایل وابستگی شبکه‌ای ندارد؛ سبد و سایر لینک‌ها نمایشی‌اند و سفارش یا پرداختی ثبت نمی‌شود. پروژهٔ کامل داخل ZIP بک‌اند، پنل و مسیرهای واقعی را حفظ کرده است.
