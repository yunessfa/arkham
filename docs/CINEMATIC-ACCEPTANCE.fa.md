# ماتریس پذیرش V4 — ارکام

این سند میان پیاده‌سازی، آزمون اجراشده و کار نیازمند دسترسی واقعی تفاوت می‌گذارد. تکمیل صددرصد درخواست، به‌خصوص اجرای Docker/VPS و تست گوشی واقعی، ادعا نمی‌شود.

## گزارش‌های اجراشده

| آزمون | نتیجه | سند |
|---|---|---|
| Django/PostgreSQL | ۶۴ موفق، شامل هم‌زمانی موجودی/verify و چهار تست ارتقای برند | `qa/reports/v4-backend-and-browser-tests.txt` |
| مرورگر خرید داخل suite بالا | ۱۵ بررسی موفق؛ ثبت‌نام، سبد، آدرس، سفارش، Mock، نظر، منع مشتری از مدیریت، ورود مدیر و CRUD | همان فایل و `qa/browser-results.json` |
| واحد فرانت‌اند و build TypeScript/Vite | ۱۱ تست موفق؛ build موفق | `qa/reports/v4-frontend-tests-and-build.txt` |
| روایت سینمایی | ۵۱ بررسی موفق؛ یک Canvas در هر هفت فصل، تغییر محصول با اسکرول، سبد واقعی API، کیبورد، unmount، fallback، reduced-motion، عرض‌های ۳۲۰/۳۹۰/۷۶۸ | `qa/reports/v4-experience.json` |
| حالت‌های لبه | ۱۱ بررسی موفق؛ نبود WebGL مستقل، لمس شبیه‌سازی‌شده، کاتالوگ خالی، کالای ناموجود و landscape کوتاه | `qa/reports/v4-edge-cases.json` |
| Compose/Dockerfile | ۹ بررسی ساختاری موفق؛ **اجرای Docker نیست** | `qa/reports/v4-compose-static.json` |

شمارش ۱۵ بررسی خرید را دوباره به ۶۴ تست Django اضافه نکنید؛ آن سناریو یکی از تست‌های همین suite است. گزارش‌های V3 و بدون پیشوند متعلق به نسخه قبلی‌اند، مگر browser-results.json که سناریوی جاری آن را دوباره نوشته است.

## اصلاحاتی که در آزمون پیدا و رفع شدند

- تداخل رنگ متن Hero قدیمی با زمینه کرم؛ سبک scoped جایگزین شد.
- کنتراست نامناسب متن در گذار روشن/تیره؛ رنگ متن مستقیماً از روشنایی زمینه انتخاب و تست شد. این تست عددی، گواه انطباق کامل WCAG کل سایت نیست.
- بیرون‌زدن سر زنبور از قاب؛ محدوده مسیر اصلاح شد.
- شیشه بیش‌ازحد روشن و مدار روی برچسب؛ متریال عسل/شیشه و عمق مدار تنظیم شد.
- اندازه کنترل محصول در موبایل؛ ابعاد صریح و عدم shrink اضافه شد، تست حداقل اندازه دوباره موفق شد.
- شکست بد تیتر فارسی موبایل؛ شکست سطر معنایی حفظ شد.
- عکس کامل کاتالوگ پیش از reveal ردیف دوم ناقص بود؛ برای پیش‌نمایش کامل، قبل از تصویرگیری صفحه اسکرول می‌شود. رفتار reveal سایت حذف نشده است.

## آنچه این خروجی انجام نمی‌دهد

این نسخه روی سرور شما نصب نشده، Git شما را تغییر نداده، .env یا رمز شما را ندارد، داده واقعی فروشگاه را پاک نکرده و درگاه واقعی را فعال نکرده است. برای حفظ اطلاعات، `CINEMATIC-V4.fa.md` را پیش از استقرار بخوانید. مسائل تجاری و مالی باز در `STATUS.fa.md` باقی‌اند.

- بازبینی نهایی fallback: رنگ و ابعاد و تایپوگرافی نمای دوبعدی از CSS قدیمی جدا شد؛ build و حالت‌های لبه دوباره بررسی شدند.
