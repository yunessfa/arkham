# تصاویر نسخه دمو

تصاویر محصول، چشم‌انداز کندو، عسل/صبحانه و بنر با هوش مصنوعی برای این نسخه ساخته شده‌اند؛ عکس کالای واقعی یا مدرک کیفیت/محل برداشت نیستند. نشان رسمی ارسال‌شده مالک با حفظ شکل روی برچسب پنج محصول تک‌شیشه‌ای ترکیب شده است. تصویر جعبه هدیه، بسته‌بندی نمایشی است.

فایل‌های WebP در `backend/demo_assets/` همراه کد هستند و فرمان `seed_demo` آن‌ها را به MEDIA_ROOT محیط محلی کپی می‌کند. دیتابیس و رسانه‌های runtime در ZIP قرار ندارند. هنگام اجرای دمو بنر هشدار عمومی و توضیحات کامل محصول نمایش داده می‌شوند. پیش از فروش واقعی، تصاویر و اطلاعات نمونه باید جایگزین شوند.

کتابخانه Lenis با مجوز MIT است؛ متن مجوز در `docs/licenses/Lenis-MIT.txt` قرار دارد. سایر وابستگی‌ها تابع مجوزهای خود هستند.
